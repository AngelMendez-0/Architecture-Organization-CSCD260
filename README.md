# Architecture & Organization

## Description
This repository contains my coursework from CSCD 260 (Computer Architecture and Organization). Topics include digital logic, data representation, assembly concepts, memory organization, and how software interacts with hardware.

## File Descriptions

### Lab 1
Contains ARM assembly programs developed for a computer architecture lab using the CPUlator simulator (ARM DE1-SoC). The lab focuses on fundamental assembly operations including arithmetic computation, register manipulation, and instruction constraints.
